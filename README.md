## 🚀 Featured Project

### [CASA — Core Agentic Security Assessment](https://github.com/Sobhan-BH/casa-agent)

> Authorization-first security assessment platform for controlled, permitted targets — with explicit scope management and an enforcement-level Authorization Gate.

- **17 assessment modules** — recon, HTTP/DNS/TLS analysis, discovery, cookie & CORS analysis, API security, info disclosure, attack-surface mapping and more
- **Finding lifecycle** — `OPEN → FIXED / STILL_PRESENT / CHANGED / UNVERIFIED` for remediation verification and repeat assessments
- **Deterministic risk engine** — explainable, multi-factor scoring; the AI layer can annotate but never alter severity
- **AI-assisted analysis** — provider-agnostic (offline heuristic or any OpenAI-compatible endpoint)
- **Quality-gated** — 94 automated tests + a 50-check validation harness, E2E-tested against a deliberately vulnerable local lab
